# Campus Support Desk — Frontend

This repository contains the Angular frontend for the Campus Support Desk project.

Quick start

1. Install dependencies:

```bash
npm install
```

2. Run the app locally:

```bash
npm start
```

Update repository URL

Replace the `repository` fields in `package.json` with your GitHub repository URL before publishing.

Push to GitHub

After initializing git locally, add your remote and push:

```bash
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```
